# 我的英文單字故事本

這是一個可以直接在本機、手機瀏覽器或 GitHub Pages 使用的英文單字學習網頁 app。練習內容以伊索寓言與童話故事為靈感，每張卡提供單字、搭配詞、例句和故事提示，讓你把單字慢慢延伸成自己的英文故事句。

公開網址：

```text
https://andy64556-arch.github.io/japanese-study/
```

## 功能

- 寓言與童話路線：龜兔賽跑、獅子與老鼠、灰姑娘、醜小鴨
- 單字卡：詞性、中文意思、使用情境、搭配詞、例句與句型模板
- Story Builder：用收集到的單字寫故事句，逐步累積成完整段落
- 主題背景：每個故事路線使用生成圖片作為學習場景
- 小測驗、筆記、故事句保存與收集進度
- 所有草稿、筆記和進度都保存在瀏覽器 `localStorage`

## 使用方式

直接開啟 `index.html`，或使用公開網址。

如果你想在本機用網址方式開啟，可以使用任何本機靜態伺服器，例如 VS Code 的 Live Server。若你的電腦有 Python，也可以用：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然後打開：

```text
http://127.0.0.1:4173/index.html
```

公開網址可直接在手機瀏覽器打開；學習進度和筆記會保存在各裝置自己的瀏覽器中。

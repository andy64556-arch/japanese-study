# 我的英文練習室

這是一個可以直接在本機使用的英文學習網頁 app。打開 `index.html` 就能開始練習，不需要登入或安裝套件。

公開網址：

```text
https://andy64556-arch.github.io/japanese-study/
```

## 功能

- 4 週、共 28 天的英文自學路線
- 每天 20 分鐘練習流程：暖身、句型、跟讀、筆記
- 英文例句與單字播放，使用瀏覽器內建語音
- 口說記錄，支援瀏覽器語音辨識時可直接錄音轉文字
- 小測驗、每日筆記、完成進度與連續天數
- 所有草稿、筆記和進度都保存在瀏覽器 `localStorage`

## 使用方式

直接開啟 `index.html`。

如果瀏覽器限制語音或錄音權限，可以改用任何本機靜態伺服器開啟，例如 VS Code 的 Live Server。若你的電腦有 Python，也可以用：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然後打開：

```text
http://127.0.0.1:4173/index.html
```

錄音功能需要瀏覽器允許麥克風權限；不支援語音辨識時，仍可手動輸入口說內容。
